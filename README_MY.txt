NEXORA Android Project
======================

ပါဝင်သောအရာများ
- NEXORA dark / gold / emerald green theme
- Telegram Bot ၇ ခုအတွက် Button များ
- Button နှိပ်လျှင် Telegram app သို့မဟုတ် သက်ဆိုင်ရာ link ကိုဖွင့်ပေးမည်
- Download Earn referral link ကို မူရင်းအတိုင်း ထည့်ထားသည်

APK တည်ဆောက်ရန်
1. Android Studio ကို ကွန်ပျူတာတွင် install လုပ်ပါ။
2. ဒီ ZIP ကို extract လုပ်ပါ။
3. Android Studio > Open > NEXORA_Android_Project folder ကိုရွေးပါ။
4. Gradle Sync ပြီးသည်အထိစောင့်ပါ။
5. Build > Build Bundle(s) / APK(s) > Build APK(s) ကိုနှိပ်ပါ။
6. APK ကို app/build/outputs/apk/debug/app-debug.apk တွင်ရနိုင်ပါသည်။

မှတ်ချက်
- ဒီဖိုင်သည် Android Studio source project ဖြစ်ပြီး install လုပ်လို့ရသော APK မဟုတ်သေးပါ။
- Telegram bot များ၏ ဝန်ဆောင်မှု၊ ဆုကြေးနှင့် ငွေပေးချေမှုများကို NEXORA က အာမခံခြင်းမရှိပါ။
- Bot တစ်ခုချင်းစီ၏ ယုံကြည်စိတ်ချရမှုကို သီးခြားစစ်ဆေးပါ။ OTP၊ password၊ bank PIN သို့မဟုတ် wallet seed phrase များကို မပေးပါနှင့်။
